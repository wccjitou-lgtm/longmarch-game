# 标准地图底图：下载与使用说明

1. 访问自然资源部**标准地图服务**：http://bzdt.ch.mnr.gov.cn
2. 下载"中华人民共和国全图"标准地图（**必须带审图号**，形如 GS(20XX)XXXX 号）：
   - 选版面简洁、含省界的比例尺系列（如 1:1600 万或 1:960 万），取栅格版（JPG/PNG）；
   - 下载时**截图留档**（记录审图号、比例尺、下载日期）。
3. 命名为 `base_map.jpg`（PNG 则 `base_map.png`）放入本文件夹。
4. 在本文件夹新建 `审图号.txt`，写一行：审图号 + 比例尺 + 下载日期。页面脚注和 README 会引用它。

## 使用红线（重要）

- **不得**对底图做拉伸变形、改色、修改省界/国界等任何内容改动，只允许整体裁剪；
- 长征路线、节点图标等属于叠加在底图上的"专题要素"，为正当用法；
- 页面上任何"像地图"的新图形，只能是本底图的裁剪，或不含任何境界线并标注"示意图"的抽象图示；
- 页面脚注固定标注："底图：自然资源部标准地图服务网站下载，审图号 GS(20XX)XXXX 号；本作品仅在底图上叠加专题要素，未对底图内容作任何修改。"
