# 万水千山·长征路 —— 长征时空地图互动策略网页

以中央红军长征路线为时空主轴的地图互动策略游戏：玩家化身红军指挥员，在于都、湘江、遵义、赤水河、金沙江、彝海、安顺场、泸定桥、夹金山、草地、腊子口等 **12 个关键节点**上，依据游戏内呈现的**地形、海拔、气候、水文、地貌风险、行军距离**等科学数据做出行军与作战决策。

- 每站流程：角色对话 → **科学研判**（数据 + 交互计算工具）→ 关键决策 → 即时反馈（选错可看到具体的**失败推演**，选对展示**历史上的真实选择**）
- 共 **11 个决策关**；到达吴起镇结算，**决策正确率 100%（全部首次答对）** 才算长征胜利
- 每题有两段免费【提示】（第一次指出该看哪个数据，第二次直接排除一个错误选项），不扣分
- 无需注册、登录或填写任何个人信息；不依赖任何 API 密钥或外部网络接口

## 二、游戏规则说明

1. 点击【开始长征】进入地图页。地图上：红色实线是已走过的路段，虚线是未走的路段，★ 星形节点即关键节点（灰色=未到达、金色脉冲=当前、红色=已完成）。
2. 地图支持滚轮/双指缩放和拖动。点击当前节点（或底部节点卡【进入节点】）开始本站剧情。
3. 每站依次经历：**剧情对话**（点击对话框推进，可跳过）→【📊 科学研判】（本站科学数据与计算工具，建议先看）→【⚔ 做出决策】。
4. 决策为 3 选 1：
   - **选对**：展示"历史上的真实选择"注解，继续前进；
   - **选错**：展示"失败推演"——敌方团长会具体讲解这个选择如何葬送大军，然后回到决策点重选；该站记 1 次**失误**。
5. 每题旁有【💡 提示】按钮，可点两次：第 1 次提示该看哪个数据，第 2 次直接排除一个错误选项。提示免费、不影响计分。
6. 走完 12 站到达吴起镇，结算页显示**决策正确率**：
   - **100%**（11 个决策全部首次答对）→ 长征胜利结局；
   - 否则显示"历史已被改写"及全部失误节点，鼓励重新挑战。
7. 进度自动保存在本机浏览器中（不涉及个人信息），关掉页面再打开可继续，包括第一站尚未完成的进度与失误记录；结算页可【重新挑战】。字段损坏或节点越界的存档不会被载入。

## 三、历史照片（可选素材）

游戏支持在**每个事件节点**展示真实历史照片（显示在对话框上方，点击可放大）：

1. 打开项目根目录的 `历史照片/` 文件夹，里面已按 12 个节点建好子文件夹；
2. 把照片放进对应文件夹（jpg/png/webp 均可，建议每站 1—4 张）——**照片文件名就是游戏里显示的说明文字**，请用简短中文命名，如 `红军夜渡于都河.jpg`；
3. 双击项目根目录的 **`更新照片.bat`**，然后刷新游戏页面即可；
4. 版权提示：请使用公有领域历史影像或已获授权照片（纪念馆公开资料等），并在作品说明中注明来源。

## 四、科学信息（"险阻解码"内容）

每个险阻节点至少呈现两类科学信息，并做成可操作的交互组件：

| 组件 | 内容 | 出现节点 |
|---|---|---|
| 水文数据 | 江面宽度、流速（对比人的游泳速度）、渡河工具 | 于都、湘江、金沙江、安顺场 |
| **渡江运力计算器** | 拖动滑杆估算渡江天数；金沙江侧重运力与统一组织，安顺场对比情景中的敌军抵达时间 | 金沙江（7 船 2 万人）、安顺场（2 船 3 万人） |
| **行军速度计算器** | 湘江使用里/天，泸定桥使用里/小时，计算行军时间并与时限对比 | 湘江、泸定桥（240 里 / 24 小时） |
| **地形高程剖面图** | 沿路线的海拔剖面，滑动查看各点海拔 | 夹金山（2000→4114 米）、腊子口 |
| **气温-海拔计算器** | 按每升高 100 米降温约 0.6℃ 计算山顶温度 | 夹金山 |
| **沼泽分层剖面图** | 草甸/泥炭/明水可点击交互，展示"表面绿茵、下面泥潭"的成因与风险 | 松潘草地 |

科学原理与各数据的出处、口径见 `docs/科学依据.md`。

## 五、地图合规声明

- 底图：**自然资源部标准地图服务**网站（http://bzdt.ch.mnr.gov.cn ）下载的"中国地图 1:1000 万 对开（竖版）"，**审图号 GS(2022)4312 号**；
- 本作品仅在底图上叠加长征路线、节点图标等**专题要素**，**未对底图内容作任何修改**（底图文件仅做等比缩放）；
- 原始底图文件与审图号记录见 `assets/map/`；
- 页面内所有"示意性图示"（沼泽剖面、态势说明等）均不含境界线要素。

## 六、技术说明

- 纯静态网页：HTML + CSS + 原生 JavaScript，无构建工具、无第三方运行库、无任何外部网络请求；
- 采用经典 `<script>` 加载（非 ES Modules、无 fetch），保证 `file://` 协议双击直开；
- 图片资源为本地 WebP（现代浏览器均支持）；角色立绘由 AI 生成后经程序切分、抠透明底处理；
- 进度保存使用 localStorage（仅本机，无个人信息）；
- 响应式适配手机竖屏（375px）至桌面宽屏（1920px）。

## 九、开发验证

游戏运行不需要 Node.js 或任何额外依赖。开发回归测试需要 Node.js，以及现有的 Playwright 和 Chromium 测试环境：

```powershell
node tests/regression.cjs
node tests/regression.cjs --full
```

第一条检查已修复的地图交互（包括双指缩放、取消手势后的键盘复位）、存档校验与终点重载、提示重试、异常音量、计算器边界与文字布局、手机结算布局；`--full` 还遍历 12 站、全部 22 个错误选项、提示与重试、照片、音乐和禁用存储的场景。测试默认通过 `file://` 运行，并在系统临时目录保存截图和结果；任何检查失败都会返回非零退出码。

已有 Playwright 不在项目模块搜索路径时，可通过 `PLAYWRIGHT_MODULE` 指定它的安装目录，通过 `PLAYWRIGHT_CHROMIUM` 指定现有 Chromium 可执行文件。`TEST_OUTPUT` 可指定项目之外的截图和结果目录；`GAME_URL` 可用于检查现有的本地 HTTP 服务。上述变量只用于测试，不影响游戏，也不需要修改系统全局配置。
